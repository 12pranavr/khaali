What else was on the table
Every number on this page is invented. No operator feed, no traffic subscription and no ticketing integration is connected to khaali. The departures are synthetic, the road delay is a number somebody typed, and the passenger demand is a deterministic model — the same scenario, seed and clock always produce the same answer, so a refresh never changes the recommendation on its own.

khaali does not reserve a place on a bus or a metro. The capacity checks are about whether it is sensible to send somebody to a departure, not a promise that they will get on it.

The recommendation is not stored here. These controls set conditions; the planner works out the answer from them. Nothing in this panel says which vehicle should win.
